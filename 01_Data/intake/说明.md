# 统一资料入口

人只把文件或文件夹放进 `01_Data/intake/inbox`。系统不扫描其他盘符，也不移动来源文件。

审核通过后，原件复制到：

- `01_Data/archive/company` 公司归档
- `01_Data/archive/personal` 个人归档

复制后核对 SHA-256。失败则不会写入正式知识或已确认的项目事实。知识笔记写到 `00_Vault/知识/`。结构化事实写进同一个 `01_Data/epcs_intelligence.db`（该文件不入库）。

```text
python 01_Data/scripts/intake_slice.py --root <根目录> submit
python 01_Data/scripts/intake_slice.py --root <根目录> reviewer --name 姓名 --org-name 单位 --org-code 编码
python 01_Data/scripts/intake_slice.py --root <根目录> approve --document <资料ID> --reviewer <人员ID> --reason 理由
python 01_Data/scripts/intake_slice.py --root <根目录> reject --document <资料ID> --reviewer <人员ID> --reason 理由
```

相同内容按 SHA-256 识别为同一资料。文件名相同但内容不同，不会合并成一条正式事项。
